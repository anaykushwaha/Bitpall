# Getting started

## Prerequisites

- Node.js 20+
- pnpm 9+

## Install

```bash
pnpm install
```

## Check the compiler

```bash
pnpm check
pnpm test
```

## Run the example

```bash
pnpm example:ransomware
```

## Start the playground

```bash
pnpm dev
```

Load the default ransomware policy, click **Check**, then **Run Simulation**.
